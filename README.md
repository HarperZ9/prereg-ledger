# prereg-ledger

An append-only record of preregistration fingerprints: `ATTESTATIONS.md` names each preregistration, its SHA-256, and what the hash covers. Entries are never edited; a correction is a new entry. Local file paths in the entries are kept as written, for integrity, and point to files on the author's machine. Entries 28 to 89 were written between 4 and 16 October 2026 and first pushed on 18 October 2026, so their outside timestamp starts on that date.
